# Content (UX writing)

Words are interface. Biowave copy is **clear, calm and specific** in both languages.

## Voice
| We are | We are not |
|---|---|
| Direct — say what happened and what to do | Vague ("Something went wrong") |
| Respectful — neutral, professional | Casual, jokey, blaming the user |
| Precise — exact names, times, counts | Approximate ("a few devices") |

## Rules
- **Sentence case** for everything: titles, buttons, labels, menu items.
- **Buttons start with a verb** and name the result: "Add device", "Approve request". Avoid "OK", "Yes", "Submit".
- **No trailing punctuation** on labels, buttons, titles. Full stop on helper text and full sentences.
- **No exclamation marks.** Use "…" (one character) for in-progress text: "Syncing…".
- **Errors** say what happened + how to fix it: "Device unreachable. Check its network cable and try again."
- **Dates and times:** 24-hour time in admin views; dates as `15 Oct 2026` (en) / `15 أكتوبر 2026` (ar). Western digits for data (D-10).
- **Names of people and devices** are never translated.

## Arabic
- Modern Standard Arabic (فصحى مبسطة), not dialect.
- Do not translate word-for-word; write the Arabic first when possible.
- No "left/right" in copy; use "start/end" concepts or describe the element.
- Allow 20–30% more space than English. Never truncate Arabic in the middle of a word.

## Examples
| Context | English | Arabic |
|---|---|---|
| Primary button | Save changes | حفظ التغييرات |
| Destructive confirm | Delete user | حذف المستخدم |
| Empty state | No devices yet. Add your first device to start tracking attendance. | لا توجد أجهزة بعد. أضف أول جهاز لبدء تسجيل الحضور. |
| Success toast | Request approved | تمت الموافقة على الطلب |
| Error | Couldn't connect to the device. Check the network and try again. | تعذر الاتصال بالجهاز. تحقق من الشبكة وحاول مرة أخرى. |
| Loading | Syncing… | جارٍ المزامنة… |
