## 0. Why
Today spacing is one flat scale (`none … 11xl`) with the same value on Web, Tablet and Mobile. Problems found in the 2026-10-29 review:
1. No platform-aware layout spacing — designers guess the gap between sections, cards and fields on each platform.
2. Descriptions name components we do not have (tabs, accordion, pagination, notification), contradict each other (form label gap in `lg` and `xl`, card padding in `3xl` and `4xl`) and the 8 `control/*` tokens have none.
3. `4xl … 11xl` are not used by any component (only listed in docs) and crowd the picker.
4. Figma scope is `GAP + WIDTH_HEIGHT`, so spacing shows up in width/height fields.

## 1. The model (put this in the guideline, §4)
Every space answers **"between what and what?"**

| Level | Tokens | Platform modes | Use for |
|---|---|---|---|
| **Control** | `spacing.control.padding-inline.{sm,md,lg,xl}`, `spacing.control.gap.{sm,md,lg,xl}` | no — the platform picks the control size | Inside a control with a fixed height. The step always equals the control size. |
| **Component** | `spacing.{none,xxs,xs,sm,md,lg,xl,2xl,3xl}` (0–24) | no | Inside one component that has no fixed height. |
| **Layout** (new) | `platform.spacing.layout.{section,group,stack,container}` | **Web · Tablet · Mobile** | Between components on a page, and from a container's edge to its content. |

Decision order for designers and developers:
1. Inside a control with a height → `control/*` with the **same size** as the control.
2. Inside one component → component scale.
3. Between components, or container edge → content → `layout/*`.

### 2.2 `2-foundations/tokens/platform/{web,tablet,mobile}.json` — new `spacing.layout` group
Add under the platform root, next to `grid` (same structure as `grid.gutter`: `$type: dimension`, `$value` aliasing the primitive, e.g. `{primitive.dimension.40}`). Same `$description` in all three files.

| Token | Web | Tablet | Mobile | `$description` |
|---|---|---|---|---|
| `spacing.layout.section` | 40 | 32 | 24 | `Layout · Vertical gap between page sections that each have their own heading. Not for: space inside a card or form.` |
| `spacing.layout.group` | 24 | 24 | 16 | `Layout · Gap between sibling blocks inside a section — cards in a row or grid, form groups, dashboard widgets. Equals grid-gutter so blocks follow the column rhythm. Not for: fields inside one form group (use layout/stack).` |
| `spacing.layout.stack` | 16 | 16 | 12 | `Layout · Gap between consecutive items in a vertical flow inside a container — section heading to content, field to field, paragraph to paragraph, content to the actions row. Not for: icon-to-text or other gaps inside one component.` |
| `spacing.layout.container` | 24 | 24 | 16 | `Layout · Padding from the edge of a surface container to its content — card, dialog, side panel, bottom sheet. Not for: controls, list rows or tooltips (use control/* or the component scale).` |

Group `$description`: `Layout spacing between components. Changes per platform: set the frame's 6. Grid & Layout mode (Figma) or data-platform / BwLayout (code).`
